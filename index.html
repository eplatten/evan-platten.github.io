CellscapeXR — Interactive 3D Spatial Transcriptomics Viewer

My Master's research at the Goergen Institute: a fully interactive 3D environment for exploring and teaching spatial transcriptomics. Researchers navigate, query, and inspect Visium HD datasets in real time, with expression data.

Built around a cross-scene event system enabling dataset hot-swapping, modular UI, and a state-driven guided tutorial. It contains point-cloud rendering at scale, and I resolved cross-platform build issues for both WebGL and standalone targets.

Supporting the application is a Python / AnnData export pipeline with resolution-preserving data-reduction strategies for 8 µm Visium HD bins and bin2cell Cell Level data — keeping rendering tractable without sacrificing spatial detail.
